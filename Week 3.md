# Week 3

## Learning Activities & Resources

This week I spent some time learning how WordPress sites can be exported and imported between installations. Since I already had a WordPress site created previously for the assignment, I wanted to understand how the export/import process works so that the site could be recreated for the practical task.

I looked at documentation and guides explaining how WordPress handles exporting site content and migrating it into a new installation.

Resources consulted included:

- WordPress Import/Export documentation  
  https://wordpress.org/documentation/article/tools-import-screen/

- WordPress support guide on exporting content  
  https://wordpress.org/documentation/article/tools-export-screen/

These resources helped me understand the process of exporting site content from one WordPress installation and importing it into another site.

## Content Insights

Through looking into how WordPress handles exporting and importing sites, I learned that WordPress separates site content from the core system files. The export process mainly transfers posts, pages, media references, and other content using an XML file, which can then be imported into another WordPress installation.

During this process I also learned that themes and plugins are not included in the content export, meaning they need to be installed separately in the new WordPress installation before the site appears the same as the original. After importing the content, I needed to reinstall the theme that was used previously and activate it so that the layout and styling of the site matched the original version.

This helped me understand that a WordPress site is made up of several components including the WordPress core system, themes, plugins, and the database content. When recreating a site, these elements needed to be configured correctly in order for the site to function and display properly.
