# Week 4

## Learning Activities & Resources

This week I spent some time learning about how local development environments work and how they can be used to run dynamic websites on a local machine. In order to complete this practical task, I needed to understand how tools like XAMPP provide a full web server stack locally.

I looked through some documentation and guides explaining how XAMPP works and how WordPress can be installed locally using Apache and MySQL. These resources helped me understand how a local environment can simulate a real web hosting setup on a personal computer.

Resources consulted included:

- XAMPP documentation  
  https://www.apachefriends.org/index.html

- WordPress installation guide  
  https://wordpress.org/documentation/article/how-to-install-wordpress/

- A tutorial explaining how to run WordPress locally with XAMPP  
  https://youtu.be/vPctfWZ0R7A

These resources helped me understand the process of setting up a local development environment and connecting a dynamic website to a database.

## Estimated Hours

Approximately 2 hours of learning and reviewing documentation.

## Content Insights

Through setting up XAMPP and installing WordPress locally, I learned how a local development environment replicates the components of a real web server. XAMPP provides Apache for serving web pages, MySQL for managing databases, and PHP for running server-side code.

I also learned how WordPress connects to a database during installation. After creating a database in phpMyAdmin, WordPress automatically created the required tables during the installation process. This showed me how dynamic websites rely on databases to store content such as posts, pages, and user information.

Running the site through the `localhost` address helped me understand that the website is being served directly from my own computer rather than from an external hosting provider.

---

## Career / Employability / Learning Insights

Learning how to run websites locally is an important skill for web development. Local environments allow developers to build and test websites safely before deploying them to a live server. This reduces the risk of breaking a production website while making changes.

This week also showed me the importance of understanding the tools used in development environments. While platforms like WordPress make it easy to build websites, understanding how the server, database, and application interact helps when troubleshooting problems or moving sites between environments.

From a learning perspective, this task reinforced that setting up development tools is an important step in many technical workflows. Taking time to understand how the environment works makes it easier to experiment and test changes during development.
