## Content Insights

Setting up the local environment helped me better understand how the different parts of a web application work together. Before this, I mainly interacted with websites through hosting platforms or CMS interfaces, so the server and database aspects were mostly hidden. Installing WordPress locally made it clearer that a website like this relies on several components working together, including the web server, the database, and the application itself.

One thing that stood out during the process was how WordPress automatically created its database structure during installation. After connecting the database, WordPress generated multiple tables that store different types of site information such as content, users, and settings. Seeing this happen helped me understand that most CMS platforms are essentially structured database systems that dynamically generate pages from stored content.

## Career / Employability / Learning Insights

Working with a local development environment highlighted how important it is to have a safe space to test and experiment when building websites. In many cases, changes made directly on a live website could break functionality or affect users. Being able to run a full website locally allows developers to test changes, experiment with features, and fix problems before deploying updates to a production server.
